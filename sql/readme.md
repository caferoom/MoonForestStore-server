

### 后台系统用户模块
管理员表 (admin): 存储可以登录后台系统的用户账号

### 用户模块
用户表 (user): 存储用户的基本信息。
地址表 (address): 存储用户的收货地址。
地区表 (region): 存储地理位置信息。省份,城市,区县信息.

### 商品模块
商品表 (product): 存储商品的基本信息。
商品分类表 (product_categories): 存储商品分类信息。
商品图片表 (product_images): 存储商品的图片信息。
商品SKU表 (product_sku): 存储具体的 SKU 信息（商品的一个变种），如红色的 M 码、蓝色的 L 码等。
商品规格定义表(product_spec): 定义商品有哪些规格（如颜色、尺码等） 
商品规格值表(product_spec_value): 存储规格的具体值 (如红色、蓝色; M、L)。

### 支付模块

优惠券表 (Coupons): 存储优惠券信息。
